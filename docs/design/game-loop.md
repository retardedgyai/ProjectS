# ProjectS Game Loop

## Core Concept

ProjectSは共存型MMOを目指す。

別々のプレイスタイルが同じ世界で価値を持つ。

## 基本ループ

戦闘:

PvE → 素材・MOD素材入手 → 装備更新 → 高難度PvE

採取:

採取 → 素材供給 → 売却・製造 → 経済参加

製造:

素材加工 → 装備製造 → プレイヤー販売 → 評価・熟練度向上

## 導線

序盤:

- 純粋なRPGとして開始
- 剣・弓・杖を試す
- 戦闘、スキル、装備更新を体験

生活職:

- 最初から利用可能
- ただし必須ではない
- 任意クエストで導線を作る

## パーティー

Lv1から利用可能。

ソロでも進行可能。

パーティーは一緒に遊ぶ楽しさと少しの効率向上を提供する。

## エンドゲーム

Lv45到達後、最初の島の最終ボス撃破で解放。

エンドゲームでは:

- 高難度攻略
- 装備厳選
- MOD構築
- 経済活動
- ビルド最適化

を中心にする。
