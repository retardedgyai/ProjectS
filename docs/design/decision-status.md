## 現在の仕様決定状況

### 完了済み

- ProjectSの必須コンセプト: 共存型MMO
- Beta上限Lv45
- 標準約25時間でLv45
- Lv45到達後、最初の島の最終ボス撃破でエンドゲーム解放
- Beta装備Tier: T1〜T3
- ILv = 装備可能レベル
- 完成装備は基本的に敵から直接ドロップしない
- 製造者が装備ベースを供給
- 使用者がMOD素材で装備を仕上げる
- レアリティ = MOD枠数
- Common 1 / Uncommon 2 / Rare 3 / Epic 4
- MOD Rank 1〜3
- 装備8枠
- 軽装・中装・重装の自由装備
- 防具にも火力MODを付与可能
- 防御を捨てた火力特化は紙装甲になる
- パーティーはLv1から利用可能
- MODは共通MOD + 部位専用・得意MODの混合型
- MODはデータ駆動・タグ駆動で拡張可能にする

### 決定済み攻撃MOD

基礎火力:

1. 攻撃力 +%
2. 与ダメージ +%
3. スキルダメージ +%
4. 通常攻撃ダメージ +%

攻撃タイプ:

5. 近接ダメージ +%
6. 投射物ダメージ +%
7. 魔法ダメージ +%

適用は武器種ではなく攻撃タグで判定する。

例:

- 火球: `SKILL / PROJECTILE / MAGIC / FIRE`
- 魔法剣の斬撃: `SKILL / MELEE / MAGIC`

## 仕様決めの現在地点

次に決める項目:

> 攻撃系MODの「クリティカル・速度系グループ」

次回は、以下を一つずつ検討する。

1. クリティカル率 +%
2. クリティカルダメージ +%
3. 攻撃速度 +%
4. 詠唱速度 +%
5. 必要ならクールダウン回復速度を攻撃MOD側に含めるか、操作・リソース系へ分けるか

このグループを決めた後の予定:

1. 属性ダメージ系
2. 貫通・防御対策系
3. 状態異常・継続ダメージ系
4. 条件付き攻撃MOD
5. 防御MOD
6. リソース・回復MOD
7. 機動・操作MOD
8. 特殊MOD
9. 各MODの装着部位・数値幅・抽選重み

## 現在の開発優先順位

仕様決めとは別に、実装作業の現在優先順位はMob Editor UI。

1. Mob Editor UI
2. 装備メタデータ基盤
3. MOD定義・保存基盤
4. 製造基盤
5. 経済・マーケット

仕様決めはMob Editor開発と並行して続けてよいが、実装はこの順番を守る。

## 運用ルール

- 仕様を新しく確定したら、該当設計ファイルを更新する
- 仕様決めの終了時に、このファイルの「現在地点」を更新する
- 新しい案は捨てずに保存するが、実装優先順位は変えない
- 曖昧な部分は勝手に確定せず、未決定として残す
