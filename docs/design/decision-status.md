## 現在の仕様決定状況

### 完了済み

- ProjectSの必須コンセプト: 共存型MMO
- Beta上限Lv45
- 標準約25時間でLv45
- Lv45到達後、最初の島の最終ボス撃破でエンドゲーム解放
- Beta装備Tier: T1〜T3
- ILv = 装備可能レベル
- 完成装備は基本的に敵から直接ドロップしない
- 製造者が装備ベースを供給
- 使用者がMOD素材で装備を仕上げる
- レアリティ = MOD枠数
- Common 1 / Uncommon 2 / Rare 3 / Epic 4
- MOD Rank 1〜3
- 装備8枠
- 軽装・中装・重装の自由装備
- 防具にも火力MODを付与可能
- 防御を捨てた火力特化は紙装甲になる
- パーティーはLv1から利用可能
- MODは共通MOD + 部位専用・得意MODの混合型
- MODはデータ駆動・タグ駆動で拡張可能にする

### 決定済み攻撃MOD

基礎火力:

1. 攻撃力 +%
2. 与ダメージ +%
3. スキルダメージ +%
4. 通常攻撃ダメージ +%

攻撃タイプ:

5. 近接ダメージ +%
6. 投射物ダメージ +%
7. 魔法ダメージ +%

クリティカル・速度:

8. クリティカル率増加 +%
   - PoE型。元のクリティカル率を割合で伸ばす
   - 基礎クリティカル率への直接加算は希少・特殊効果として別に扱う
9. クリティカル倍率 +%
   - 基本クリティカル倍率150%
   - 基本倍率へ加算するPoE型
10. 攻撃速度 +%
   - 武器ごとの基準速度を残しながらMODで伸ばすハイブリッド型
11. キャスト短縮 +%
   - 魔法、弓のチャージ、大技の溜め、回復、召喚など発動準備時間を短縮する
   - 即時発動スキルには適用しない

適用は武器種ではなく攻撃・行動タグで判定する。

例:

- 火球: `SKILL / PROJECTILE / MAGIC / FIRE`
- 魔法剣の斬撃: `SKILL / MELEE / MAGIC`

### 決定済みスキル・リソース系MOD

1. クールダウン短縮 +%
   - 攻撃、回復、防御、妨害、移動などクールダウンを持つスキル全般が対象
   - 攻撃系ではなく、スキル・リソース系の「スキル回転系MOD」として扱う
   - 強いこと自体は許容し、必須化は数値幅・部位・出現重みで調整する

## 仕様決めの現在地点

次に決める大項目:

> 攻撃系MODの「属性ダメージ系グループ」

次回は、以下を一つずつ検討する。

1. Betaで採用する属性の種類
2. 属性ダメージ +% MODを採用するか
3. 属性MODは魔法だけでなく、剣・弓・通常攻撃にも適用できるか
4. 元から属性を持つ攻撃を強化する方式と、無属性攻撃へ属性ダメージを追加する方式を分けるか
5. 敵の属性耐性・弱点をどの程度使うか
6. 複数属性攻撃と属性変換をBetaへ入れるか

属性ダメージ系の後の予定:

1. 貫通・防御対策系
2. 状態異常・継続ダメージ系
3. 条件付き攻撃MOD
4. 防御MOD
5. リソース・回復MOD
6. 機動・操作MOD
7. 特殊MOD
8. 各MODの装着部位・数値幅・抽選重み

## 現在の開発優先順位

仕様決めとは別に、実装作業の現在優先順位はMob Editor UI。

1. Mob Editor UI
2. 装備メタデータ基盤
3. MOD定義・保存基盤
4. 製造基盤
5. 経済・マーケット

仕様決めはMob Editor開発と並行して続けてよいが、実装はこの順番を守る。

## 運用ルール

- 仕様を新しく確定したら、該当設計ファイルを更新する
- 仕様決めの終了時に、このファイルの「現在地点」を更新する
- 新しい案は捨てずに保存するが、実装優先順位は変えない
- 曖昧な部分は勝手に確定せず、未決定として残す
