# ProjectS 氷属性設計

## 目的

氷属性は、減速・凍結だけを行う純粋な妨害属性にはしない。

冷気によって敵の行動を段階的に制限し、凍結中の攻撃機会と氷砕きによる瞬間火力へ変換する属性とする。

## 基本戦闘ループ

1. 氷属性攻撃で氷属性直撃ダメージを与える
2. 対象の共有冷気ゲージを増加させる
3. 冷気Ⅰへ到達し、軽い減速を付与する
4. 冷気Ⅱへ到達し、減速を強化する
5. 冷気ゲージ満タンで対象を凍結させる
6. 凍結中は対象への攻撃機会が発生する
7. 凍結中に攻撃を続けるか、`SHATTER`タグを持つ直接攻撃で凍結を砕く
8. 氷砕きによって大きな瞬間ダメージを与える

火属性が継続圧力と周期的な爆発を担当するのに対し、氷属性は短い制圧時間へ火力を集中する。

## 冷気ゲージ

- 冷気ゲージは対象の敵ごとに一つの共有状態として保持する
- 氷属性攻撃は、最終氷属性値、攻撃・スキルごとの冷気係数、冷気蓄積MODなどを基準に冷気値を加算する
- 内部では連続値のゲージを使用し、プレイヤーには段階または氷結アイコンで表示する
- ゲージ進行は `冷気Ⅰ → 冷気Ⅱ → 凍結` の三段階とする

冷気Ⅰ・冷気Ⅱのゲージ境界、減速率、凍結に必要な冷気値、凍結時間などの細かな数値はコードへ固定しない。

ゲーム内管理UIから、対象カテゴリ別の標準値とモブ・ボス個別の上書き値を変更できるようにする。

## 凍結中の攻撃機会

凍結状態は単なる行動不能ではなく、攻撃チャンスとして扱う。

凍結中の対象へは追加のダメージ補正を与える方向とする。

倍率、対象プレイヤー、直接攻撃・継続ダメージの適用範囲、ボス補正は今後決める。

## 氷砕き条件

氷砕きは、凍結中の対象へ`SHATTER`タグを持つ直接攻撃を命中させた場合にのみ発生する。

- すべての攻撃が自動的に凍結を壊す方式にはしない
- `SHATTER`タグは氷属性専用ではなく、攻撃の性質を表すタグとする
- 物理・魔法・他属性の攻撃にも、設計上必要なら設定できる
- パーティー内の誰でも有効な`SHATTER`攻撃で氷砕きできる
- 武器種で固定せず、通常攻撃・スキル定義のタグで管理する
- ゲーム内スキルエディタからタグを設定・解除できるようにする

設定候補:

- 大剣・ハンマーなどの重い攻撃
- 最大チャージ射撃
- 高威力の氷槍
- 爆発系魔法
- フィニッシャースキル

## 氷砕きの処理順

1. `SHATTER`攻撃が凍結中の対象へ直撃する
2. その攻撃自体の直撃ダメージを計算する
3. 氷砕き攻撃は凍結中のダメージ増加を受ける
4. 直撃ダメージ適用後に凍結を解除する
5. 氷砕き追加ダメージを発生させる

冷気ゲージを満タンにして凍結を成立させた攻撃は、その攻撃自身が`SHATTER`タグを持っていても同時に氷砕きを発生させない。

凍結成立後、次に命中した有効な`SHATTER`直接攻撃から氷砕き可能になる。

一度の凍結状態から発生できる氷砕きは一回だけとする。

多段攻撃では、最初の有効な`SHATTER`直撃で凍結が解除され、後続ヒットは同じ凍結を再度砕けない。

## 氷砕きダメージ方式

氷砕きはフィニッシャー型とする。

氷砕き追加ダメージは、凍結を砕いた`SHATTER`攻撃そのものの直撃威力を基準に計算する。

基本形:

`氷砕き追加ダメージ = SHATTER攻撃の基準直撃ダメージ × 氷砕き倍率`

### Beta初期値

Betaの氷砕き倍率は、最初の基準として125%とする。

例:

- `SHATTER`攻撃の基準直撃ダメージ: 100
- 氷砕き倍率: 125%
- 氷砕き追加ダメージ: 125
- 元の直撃と氷砕きを合わせた合計: 225相当

この125%は固定値ではなく、初期テストでは100%〜150%を中心に調整する。

氷砕き倍率はゲーム内管理UIから変更可能にし、対象カテゴリごとの標準値と、モブ・ボス個別の上書き値を持たせる。

この方式により、軽い攻撃で砕くよりも、大剣の溜め斬り、最大チャージ射撃、高威力魔法などの重い攻撃で砕いた方が大きな氷砕きダメージを得られる。

プレイヤーは凍結中に手数を入れてダメージ増加を活用するか、早めに強い`SHATTER`攻撃を当てて瞬間火力を取るかを選択できる。

氷砕き追加ダメージは、砕いた攻撃の攻撃系統を継承する方向とする。

- 物理系統の`SHATTER`攻撃による氷砕きは物理耐久を参照する
- 魔法系統の`SHATTER`攻撃による氷砕きは魔法耐久を参照する

以下は今後決める。

- 基準直撃ダメージを防御計算前・後のどちらにするか
- クリティカル結果を氷砕き基準へ含めるか
- 氷属性値・氷砕き専用MODを倍率へどう反映するか
- 貫通を氷砕きへどう適用するか
- 氷砕き後に残す冷気量
- 氷砕きを範囲攻撃にするか
- ボス・PvPでの氷砕き補正

## デフォルトで氷砕きしない効果

以下は、`SHATTER`タグを持つ直接攻撃として明示されない限り氷砕きを発生させない。

- 継続ダメージ
- 設置物の周期ダメージ
- 多段攻撃の通常ヒット部分
- 召喚物の通常攻撃
- 爆燃などの自動発生効果
- 反射・追撃・連鎖などの二次効果

## ゲーム内管理UI

最低限、以下を調整可能にする。

- 冷気Ⅰ・冷気Ⅱのゲージ境界
- 各段階の移動速度・行動速度低下率
- 対象カテゴリ別の必要冷気値
- 凍結時間
- ボスの氷結ブレイク時間と行動制限内容
- 凍結中のダメージ増加倍率と適用対象
- 冷気ゲージの減衰開始時間と減衰速度
- 氷砕き倍率
- 氷砕き倍率のPvE・ボス・PvP別補正
- 氷砕き後に残す冷気量
- 氷砕きの範囲と周囲ダメージ倍率
- PvE・PvP補正

数値変更はテスト対象へ即時反映でき、保存前検証、標準値への復帰、ロールバック、変更履歴に対応する方向とする。
