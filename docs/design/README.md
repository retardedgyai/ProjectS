## Status Labels

- **採用済み / Accepted:** 今後の設計基準。変更時は理由と更新日を残す。
- **検討中 / Draft:** まだ固定していない案。
- **廃止 / Deprecated:** 現在は使用しないが、経緯確認のため残す資料。
