# ProjectS Equipment System

## 装備構成

Beta基本装備枠:

- 武器 x1
- 頭
- 胴
- 脚
- 靴
- 首飾り
- 指輪 x2

オフハンドは将来拡張用。

## Tier

Beta:

- T1: Lv1〜15
- T2: Lv16〜30
- T3: Lv31〜45

Tierは装備世代・素材帯を表す。

## Item Level

ILvは装備可能レベルと一致する。

高ILvほど基礎性能の抽選レンジが高い。

## 製造

完成装備は基本的に敵から直接落とさない。

プレイヤー製造者がベース装備を作る。

製造結果:

- Tier
- ILv
- 基礎性能
- レアリティ
- 製造者名

## レアリティ

- Common: MOD枠1
- Uncommon: MOD枠2
- Rare: MOD枠3
- Epic: MOD枠4

製造時はMOD自体は付かず、空き枠状態で完成する。

## 防具

軽装・中装・重装を自由装備可能。

武器による防具制限なし。

重量によって軽量・中量・重量の特性差を出す。

- 軽装: 火力・機動向け
- 中装: バランス
- 重装: 防御・耐久向け

防具にも攻撃MODを付与可能。
