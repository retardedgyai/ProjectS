# ProjectS 状態異常・継続ダメージ設計

## 基本方針

属性は、通常時の直接ダメージを常時増幅する仕組みではなく、弱点特効と属性固有の戦い方を作るために使用する。

状態異常・継続ダメージは、火・氷・雷それぞれのプレイ感を差別化する中核システムとして扱う。

## 火属性

### 決定済みの基本構造

火属性攻撃は、対象へ燃焼を付与しながら炎蓄積を増加させる。

炎蓄積が一定量に達すると、爆燃が発生して瞬間ダメージを与える。

役割は以下のように分ける。

- 燃焼: 継続的に敵へ圧力を与える
- 爆燃: 攻撃を重ねて蓄積した結果として瞬間火力を発生させる

基本的な戦闘ループ:

1. 火属性攻撃を当てる
2. 燃焼を付与・維持する
3. 炎蓄積を増やす
4. 閾値に達すると爆燃が発生する
5. 再び炎蓄積を溜める

これにより火属性は、継続ダメージだけの属性でも、一撃火力だけの属性でもなく、継続圧力と周期的な爆発力を両立する属性になる。

### 攻撃系統との関係

燃焼と爆燃も、元となった攻撃の攻撃系統に従う方向とする。

- 物理系統の火属性攻撃から発生した効果は物理耐久を参照する
- 魔法系統の火属性攻撃から発生した効果は魔法耐久を参照する

属性が火であることを理由に、別の属性耐性や別系統の防御値は参照しない。
