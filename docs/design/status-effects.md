# ProjectS 状態異常・継続ダメージ設計

## 基本方針

属性は、通常時の直接ダメージを常時増幅する仕組みではなく、弱点特効と属性固有の戦い方を作るために使用する。

状態異常・継続ダメージは、火・氷・雷それぞれのプレイ感を差別化する中核システムとして扱う。

## 火属性

### 決定済みの基本構造

火属性攻撃は、対象へ燃焼を付与しながら炎蓄積を増加させる。

炎蓄積が一定量に達すると、爆燃が発生して瞬間ダメージを与える。

役割は以下のように分ける。

- 燃焼: 継続的に敵へ圧力を与える
- 爆燃: 攻撃を重ねて蓄積した結果として瞬間火力を発生させる

基本的な戦闘ループ:

1. 火属性攻撃を当てる
2. 燃焼を付与・維持する
3. 炎蓄積を増やす
4. 閾値に達すると爆燃が発生する
5. 再び炎蓄積を溜める

これにより火属性は、継続ダメージだけの属性でも、一撃火力だけの属性でもなく、継続圧力と周期的な爆発力を両立する属性になる。

### 火属性値

火属性攻撃は、直接ダメージとは別に、その攻撃が持つ火属性性能を表す「火属性値」を持つ。

火属性値は、通常時の直撃ダメージそのものを直接増加させる値ではない。

主に以下の計算基準として使用する。

- 燃焼ダメージ
- 一回の攻撃で加算する炎蓄積量
- 爆燃ダメージ
- PvEで火弱点を突いた時の特効性能

例:

- 直接ダメージ: 100
- 火属性値: 40

この攻撃へ火属性ダメージ +50%を適用した場合、直接ダメージは100のままだが、火属性値は60として扱う。

その結果、燃焼、炎蓄積、爆燃、火弱点特効が強化される。

### 火属性ダメージ +%

火属性ビルドの基礎MODとして、以下を採用する。

- `火属性ダメージ +%`

名称はプレイヤーに理解しやすい「火属性ダメージ」を使用するが、システム上は火属性値を割合で増加させるMODとして扱う。

このMODだけでは、通常の敵へ与える直撃ダメージを常時直接増加させない。

ただし、燃焼と爆燃の性能が上がるため、戦闘全体で与える総ダメージは増加する。

火弱点を持つモブ・ボスに対しては、火属性値を基準とした弱点特効も強くなる。

### 火属性ビルド内の役割分担

火属性ダメージ +%:

- 火属性値全体を広く伸ばす
- 燃焼、炎蓄積、爆燃、火弱点特効を平均的に強化する
- 火属性ビルドを成立させる基礎MOD

燃焼専用MOD:

- 燃焼ダメージ
- 燃焼持続時間
- 燃焼中の対象への追加効果

など、燃焼だけを高効率で伸ばす専門MODとして扱う方向とする。

爆燃専用MOD:

- 炎蓄積量
- 爆燃ダメージ
- 爆燃範囲
- 爆燃発生後の再蓄積補助

など、爆燃だけを高効率で伸ばす専門MODとして扱う方向とする。

これにより、同じ火属性でも以下のビルドを成立させる。

- 火属性汎用型: 火属性ダメージ +%を中心に、燃焼と爆燃を平均的に扱う
- 燃焼特化型: 長時間の継続圧力を重視する
- 爆燃特化型: 蓄積から発生する周期的な瞬間火力を重視する

専用MODは対象が限定される代わりに、火属性ダメージ +%より数値効率を高くする方向とする。

### 攻撃系統との関係

燃焼と爆燃も、元となった攻撃の攻撃系統に従う方向とする。

- 物理系統の火属性攻撃から発生した効果は物理耐久を参照する
- 魔法系統の火属性攻撃から発生した効果は魔法耐久を参照する

属性が火であることを理由に、別の属性耐性や別系統の防御値は参照しない。
