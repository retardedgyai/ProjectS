# ProjectS Magic System

## 基本方針

ProjectSにおける「魔術」は、メイジという一つのクラスを指す言葉ではない。

魔術は世界に存在する力・技術・学問の総称であり、採取・製造・戦闘など複数の遊び方にまたがる共通概念として扱う。

## メイジクラスとの区別

- メイジは、魔術を戦闘へ利用することに長けたクラスの一つ
- メイジだけが魔術を扱えるわけではない
- 他クラスも、魔術を利用したスキルや属性を宿した装備を使える
- 採取者や製造者も、メイジクラスでなくても魔術分野へ関われる
- クラス選択と、魔術を利用する生産・採取活動は原則として別の軸で扱う

メイジと魔術は関連付けてもよいが、同一のものとして扱わない。

## 採取における魔術

魔術は、一般素材とは異なる魔力資源を発見・採取・安定化する分野として利用できる。

例:

- 属性結晶
- 魔力を帯びた鉱石・植物
- モンスターから得られる魔力素材
- 属性注入に使う触媒素材
- 通常の方法では採取できない魔術資源

具体的な採取方法、必要道具、熟練度は未決定。

## 製造における魔術

魔術は、装備・素材へ魔力や属性を与える加工分野として扱う。

決定済みの代表例:

- 武器・装備への属性注入
- 属性触媒の利用
- 属性ダメージ追加MODの付与

鍛冶などが装備の物理的な土台を作り、魔術加工がその装備へ属性や魔力を宿すという役割分担を作れる。

魔術加工の担当者、設備、熟練度、成功率、付け替え方法は未決定。

## 戦闘における魔術

魔術はメイジの攻撃魔法だけに限定しない。

以下のような形で、さまざまなクラス・武器・スキルに利用できる。

- 火・氷・雷などの属性攻撃
- 魔法弾や召喚などの直接的な魔術
- 魔法剣や属性弓など、武器と魔術を組み合わせた攻撃
- 防御、支援、妨害などへの魔術利用

攻撃へのMOD適用はクラス名ではなく、その攻撃が持つ性質によって判定する。

## 世界と経済における役割

魔術を横断概念にすることで、以下の経済循環を作れる。

魔術素材を採取する
↓
触媒や加工素材を製造する
↓
装備へ属性を注入する
↓
戦闘プレイヤーが属性装備を使用する
↓
新しい素材・装備需要が発生する

これにより、魔術は戦闘クラスのためだけの要素ではなく、採取者・製造者・戦闘者をつなぐ世界システムになる。

## 分かりやすさの方針

内部では自由な組み合わせを許容するが、プレイヤーには用途を分けて表示する。

例:

- 魔術採取: 魔力素材を集める
- 魔術加工: 装備へ属性や魔力を与える
- 戦闘魔術: 魔術を攻撃・防御・支援へ使う

初心者が「メイジを選ばないと魔術に関われない」と誤解しない案内を用意する。

## 未決定

- 魔術分野に独立した熟練度を持たせるか
- 採取・製造・戦闘で熟練度を分けるか
- 魔術加工をプレイヤー職、NPC施設、または両方で行うか
- 魔術設備・触媒・加工費
- 属性注入の成功率と品質
- 魔術を利用できる採取物・製造品の具体的な範囲
- メイジクラスが魔術分野に持つ固有の利点
