# ProjectS MOD System

## 基本方針

MODは装備を後からカスタマイズするシステム。

製造者はベース装備を作り、使用者はMOD素材を使って完成させる。

ProjectSでは、自由度を高く保ちながらも、プレイヤーが「どの効果が何に影響するのか」を直感的に理解できる構成を優先する。

## MOD Rank

- Rank1: T1 / ILv1〜15
- Rank2: T2 / ILv16〜30
- Rank3: T3 / ILv31〜45

## MOD枠

レアリティによって決定する。

- Common: 1枠
- Uncommon: 2枠
- Rare: 3枠
- Epic: 4枠

## 部位ルール

完全な部位専用ではなく、共通MODと部位専用・得意MODを組み合わせる。

## 攻撃を構成する二つの軸

攻撃は「攻撃系統」と「属性」を別々に持つ。

### 攻撃系統

- 物理
- 魔法

攻撃系統は、敵のどの耐久値でダメージを軽減するかを決める。

- 物理技は物理耐久で計算する
- 魔法技は魔法耐久で計算する

各攻撃は原則として物理か魔法のどちらか一方を主な攻撃系統として持つ。

Betaでは、一つの攻撃を物理耐久と魔法耐久の両方で分割計算する複雑な方式は採用しない。

### 属性

Betaでは以下を採用する。

- 火
- 氷
- 雷

属性は、どの耐久値で計算するかを変更しない。

例:

- 火属性を持つ剣技が物理技なら、火属性部分も含めて物理耐久で計算する
- 火属性を持つ火球が魔法技なら、火属性部分も含めて魔法耐久で計算する

属性は以下を作るために使用する。

- 通常攻撃・スキルの属性直撃ダメージ
- モブ・ボスの弱点特効
- 状態異常
- 攻撃の演出
- ダメージの出方
- 戦い方の違い

光と闇はBetaでは採用せず、将来の地域、クラス、ボス、装備、アップデートと結びつける追加候補として保留する。

## タグ方式

武器種だけではなく、攻撃が持つ性質でMODの適用を判定する。

例:

- 火球: `SKILL / PROJECTILE / MAGIC / FIRE`
- 火を宿した剣技: `SKILL / MELEE / PHYSICAL / FIRE`
- 雷の魔法剣: `SKILL / MELEE / MAGIC / LIGHTNING`

## 決定済み攻撃MOD

### 基礎火力

- 攻撃力 +%
- 与ダメージ +%
- スキルダメージ +%
- 通常攻撃ダメージ +%

### 攻撃タイプ

- 近接ダメージ +%
- 投射物ダメージ +%
- 魔法ダメージ +%

適用は武器種ではなく、攻撃が持つタグで判定する。

### クリティカル・速度系

#### クリティカル率

PoE型の二段階方式を採用する。

通常MOD:

- `クリティカル率増加 +%`
- 元のクリティカル率を割合で伸ばす

希少・特殊効果:

- `基礎クリティカル率 +x%`
- 元のクリティカル率そのものへ直接加算する
- 上位MOD、特殊MOD、固有装備、クラス特性などに限定する方向

最終クリティカル率の上限、Rankごとの数値幅、クリティカル可能な攻撃の範囲は未決定。

#### クリティカルダメージ

PoE型を採用する。

- 基本クリティカル倍率は150%
- `クリティカル倍率 +x%` は基本倍率へ加算する
- クリティカル率と倍率を別々に伸ばすことでクリティカル特化ビルドを成立させる

最終倍率の上限、Rankごとの数値幅、出現部位は未決定。

#### 攻撃速度

武器ごとの個性とMOD成長を両立するハイブリッド型を採用する。

- 武器種類ごとに基準攻撃速度を持つ
- 軽い武器は速く、重い武器は遅い個性を残す
- `攻撃速度 +%` で基準速度から伸ばせる
- 重い武器が簡単に軽武器と同じ操作感にならないよう調整する

基準速度、上限、Rankごとの数値幅、適用行動は未決定。

#### キャスト短縮

正式名称は「キャスト時間短縮」、MOD表示名は `キャスト短縮 +%` とする。

- 魔法の詠唱
- 弓のチャージ
- 大技の溜め
- 回復
- 召喚

など、発動前に準備時間がある行動を速くする。

即時発動スキルには適用しない。

攻撃速度は攻撃間隔、キャスト短縮は発動前の準備時間へ影響する。

上限、Rankごとの数値幅、継続発動や発動後硬直への影響は未決定。

## 属性システム

### 属性値

火・氷・雷の各属性は、それぞれ独立した属性値を持つ。

例:

- 火属性値
- 氷属性値
- 雷属性値

属性値は以下へ反映する。

- 通常攻撃・スキルの属性直撃ダメージ
- 属性固有の状態異常・蓄積・追加効果
- PvEで対応する弱点を突いた時の追加特効

属性値が直撃へ何%反映されるかは、通常攻撃・スキルごとの属性反映率で調整する。

例:

- 基礎直撃ダメージ: 100
- 火属性値: 40
- 火属性反映率: 50%
- 火属性直撃部分: 20

この攻撃が物理技なら基礎直撃と火属性直撃の両方を物理耐久で計算し、魔法技なら両方を魔法耐久で計算する。

### 属性値を追加・強化するMOD

属性を持たない装備・攻撃へ属性を追加する固定値MOD:

- `火属性値 +x`
- `氷属性値 +x`
- `雷属性値 +x`

すでに持っている属性値を割合で伸ばすMOD:

- `火属性値 +%`
- `氷属性値 +%`
- `雷属性値 +%`

ゲーム内の短縮表示では、必要に応じて以下を使用できる。

- `火属性 +%`
- `氷属性 +%`
- `雷属性 +%`

`火属性ダメージ +%` のような名称は採用しない。

属性値MODは直撃だけでなく、燃焼・凍結・連鎖・蓄積・弱点特効なども伸ばすため、`属性値 +%` の方が仕様を正確に表す。

### 属性の役割

属性値は通常の敵への直撃や固有効果にも有効になる。

ただし、属性による追加のダメージ増幅が発生するのは、PvEでモブ・ボスの弱点属性を突いた時のみとする。

つまり以下の関係になる。

- 通常の敵: 属性直撃と属性固有効果が発生する
- 弱点の敵: 通常効果に加えて弱点特効が発生する
- PvP: 弱点特効は発生しないが、属性直撃と属性固有効果は発生する

属性ごとの差は、単純な色違いではなく、攻撃の性質と戦い方で表現する。

- 火: 直撃、燃焼、炎蓄積、爆燃、継続圧力
- 氷: 減速、凍結、行動制御
- 雷: 瞬間火力、連鎖、連続ヒット、高速性

具体的な状態異常効果は `docs/design/status-effects.md` で決める。

### 属性投資ビルドの役割

属性を深く伸ばすほど、以下が強化される。

- 属性直撃ダメージ
- PvEで対応する弱点を突いた時の特効性能
- 燃焼、凍結、連鎖などの属性固有効果
- 属性を中心にした戦い方の完成度

属性を持つだけの装備と、MOD枠を使って属性へ深く投資した装備には明確な差を作る。

#### 他ビルドとの差別化

汎用火力型:

- 攻撃力、与ダメージ、物理・魔法貫通などを中心に伸ばす
- 敵の弱点に依存せず、どこでも安定して戦える
- 属性固有効果への専門性は低い

クリティカル型:

- クリティカル率とクリティカル倍率を中心に伸ばす
- 相手を選ばず瞬間火力を狙える
- 属性弱点や属性固有効果への依存は低い

単属性特化型:

- 一つの属性へMOD枠を集中させる
- 属性直撃と固有効果の両方が強い
- 対応する弱点を持つモブ・ボスへの周回効率が高い
- 対象を選ぶ代わりに、刺さった相手へ高い専門性を発揮する

複数属性型:

- 複数の属性を持ち、幅広い弱点へ対応できる
- 一つの属性へ使える投資が薄くなるため、単属性特化ほど各属性の直撃・弱点特効・固有効果は強くならない
- 「広く浅い」汎用属性ビルドとして扱う

基本関係:

- 単属性特化: 狭く深い
- 複数属性: 広く浅い
- 汎用火力・クリティカル: 属性に依存しない安定性

属性投資と通常火力MODの期待値差、弱点倍率、属性反映率、固有効果への反映量は未決定。

### 属性注入

武器や攻撃へ属性値を追加する行為を、世界観上「属性注入」と呼ぶ。

属性注入は以下と結びつける。

- 魔術
- 魔導工房
- 属性触媒
- 魔術素材
- 魔術加工

属性注入によって、装備や対応攻撃へ火・氷・雷の属性値と、その属性に応じた性質を付与する。

システム上はMOD枠と統合し、プレイヤーへの見せ方では装備へ属性を宿す加工として演出する。

属性注入の必要素材、担当、熟練度、付け替え、上書き、固定値幅は未決定。

### 複数属性

一つの武器・攻撃が複数属性を持つことを許可する。

例:

- 物理系統 / 火・雷属性
- 魔法系統 / 火・氷属性

複数属性でも、防御計算に使う耐久値は攻撃系統によって一つに決まる。

モブの弱点を突いた場合の追加増幅は一度だけ適用し、複数属性による弱点倍率の重複は行わない方向とする。

複数属性の保持上限、注入MODの重複、属性効果の同時発生ルールは未決定。

### モブ・ボスの属性弱点

属性弱点はPvEのモブ・ボスに使用する。

- 通常モブでは、知っていると少し有利になるソフトな弱点として扱う
- 一般的な装備でも攻略可能にする
- 属性完全無効はBetaでは原則採用しない
- 弱点は表示、図鑑、戦闘反応などから分かりやすく確認できるようにする

ボス周回では、弱点属性に合わせた専用装備を作る価値を大きくする。

- 初回攻略は汎用装備でも可能
- 専用ビルドで討伐速度、安定性、消耗効率を改善できる
- 周回プレイヤーがボスごとの武器・防具・MOD構成を研究できる
- 専用装備は参加条件ではなく、周回効率を詰める目標とする

弱点倍率、情報開示方法、装備セット切り替え方法は未決定。

### PvPでの属性

プレイヤーには火・氷・雷の属性弱点・属性耐性を持たせない。

PvPでは属性による弱点ダメージ増幅は発生しない。

属性直撃と属性固有効果はPvPでも残す。

属性は以下のような戦い方の違いとして扱う。

- 燃焼などの継続圧力
- 減速・凍結などのCC
- 雷の瞬間火力・連続攻撃

対策は属性耐性ではなく、CC耐性、状態異常持続時間短縮、継続ダメージ軽減などの汎用防御で行う。

PvP用の状態異常時間や連続CC対策は別途決める。

## 貫通・防御対策系

### 耐久値

防御計算に使用する基本耐久値は以下の二つとする。

- 物理耐久
- 魔法耐久

属性耐性はプレイヤー装備ステータスとして採用しない。

モブの属性相性も独立した属性耐性数値を中心にせず、弱点ボーナスを中心に扱う。

### 採用する貫通MOD

Betaでは以下の割合貫通MODを採用する。

- `物理貫通 +%`
- `魔法貫通 +%`

物理貫通:

- 物理系統の攻撃が敵の物理耐久を一部無視する
- 物理技が火・氷・雷属性を持っていても物理貫通を使用する

魔法貫通:

- 魔法系統の攻撃が敵の魔法耐久を一部無視する
- 魔法技が火・氷・雷属性を持っていても魔法貫通を使用する

属性貫通は採用しない。

### 採用しない貫通MOD

- 火属性貫通
- 氷属性貫通
- 雷属性貫通
- 全属性貫通
- 全耐久貫通
- 固定値貫通

Betaでは割合貫通に統一する。

### 貫通と耐久低下の区別

貫通:

- 装備者本人だけが恩恵を受ける
- 自分の攻撃が敵の対応耐久を一部無視する

耐久低下:

- 敵へ弱体効果として付与する
- 原則としてパーティー全員が恩恵を受ける
- 物理耐久低下、魔法耐久低下を用意できる
- タンク、支援、妨害役がパーティー火力へ貢献する手段にする

貫通上限、Rankごとの数値幅、耐久低下の重複、計算順序、耐久値の下限は未決定。

## 決定済みスキル・リソース系MOD

### クールダウン短縮

MOD表示名は `クールダウン短縮 +%` とする。

- 攻撃、回復、防御、妨害、移動など、クールダウンを持つスキル全般へ適用する
- 攻撃系ではなく、スキル・リソース系のスキル回転MODとして扱う
- 一回の威力を伸ばすか、使用回数を増やすかを選択できるようにする
- 強いこと自体は許容し、必須化は数値幅、出現部位、出現重みで調整する

上限、Rankごとの数値幅、適用対象外スキル、チャージ制スキルへの適用は未決定。

## 拡張性

MODはコードへ直接散在させず、以下をデータ化する。

- 効果
- Rank
- 数値幅
- 部位
- タグ
- 条件
- 出現重み

将来的な武器、魔術、属性、状態異常追加に対応する。
