# ProjectS MOD System

## 基本方針

MODは装備を後からカスタマイズするシステム。

製造者はベース装備を作り、使用者はMOD素材を使って完成させる。

## MOD Rank

- Rank1: T1 / ILv1〜15
- Rank2: T2 / ILv16〜30
- Rank3: T3 / ILv31〜45

## MOD枠

レアリティによって決定:

- Common: 1枠
- Uncommon: 2枠
- Rare: 3枠
- Epic: 4枠

## 部位ルール

完全な部位専用ではなく、共通MOD + 部位得意MODの混合型。

## タグ方式

武器種ではなく攻撃タグで判定する。

例:

- 火球: SKILL / PROJECTILE / MAGIC / FIRE
- 魔法剣: SKILL / MELEE / MAGIC

## 決定済み攻撃MOD

基礎火力:

- 攻撃力 +%
- 与ダメージ +%
- スキルダメージ +%
- 通常攻撃ダメージ +%

タイプ:

- 近接ダメージ +%
- 投射物ダメージ +%
- 魔法ダメージ +%

## 拡張性

MODはコードへ直接散在させず、以下をデータ化する。

- 効果
- Rank
- 数値幅
- 部位
- タグ
- 条件
- 出現重み

将来的な武器、魔術、属性、状態異常追加に対応する。
