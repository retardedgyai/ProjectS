# ProjectS MOD System

## 基本方針

MODは装備を後からカスタマイズするシステム。

製造者はベース装備を作り、使用者はMOD素材を使って完成させる。

## MOD Rank

- Rank1: T1 / ILv1〜15
- Rank2: T2 / ILv16〜30
- Rank3: T3 / ILv31〜45

## MOD枠

レアリティによって決定:

- Common: 1枠
- Uncommon: 2枠
- Rare: 3枠
- Epic: 4枠

## 部位ルール

完全な部位専用ではなく、共通MOD + 部位得意MODの混合型。

## タグ方式

武器種ではなく攻撃タグで判定する。

例:

- 火球: SKILL / PROJECTILE / MAGIC / FIRE
- 魔法剣: SKILL / MELEE / MAGIC

## 決定済み攻撃MOD

### 基礎火力

- 攻撃力 +%
- 与ダメージ +%
- スキルダメージ +%
- 通常攻撃ダメージ +%

### 攻撃タイプ

- 近接ダメージ +%
- 投射物ダメージ +%
- 魔法ダメージ +%

### クリティカル・速度系

#### クリティカル率

PoE型の二段階方式を採用する。

通常のクリティカル率MOD:

- `クリティカル率増加 +%`
- 元々のクリティカル率を割合で伸ばす
- 例: 元が5%で、クリティカル率増加+20%なら最終的に6%

希少・特殊なクリティカル率効果:

- `基礎クリティカル率 +x%`
- 元々のクリティカル率そのものへ直接加算する
- 通常MODより強いため、上位MOD、特殊MOD、ユニーク効果、クラス特性などへ限定する方向

通常のクリティカル率増加と基礎クリティカル率加算は両方存在できる。

最終的なクリティカル率上限、Rankごとの数値幅、どの攻撃がクリティカル可能かは未決定。

#### クリティカルダメージ

PoE型を採用する。

- 基本クリティカル倍率は150%
- 通常ダメージ100に対し、クリティカル時は150ダメージ
- `クリティカル倍率 +x%` は基本倍率へ加算する
- 例: 基本150%にクリティカル倍率+50%が付くと、最終倍率は200%
- クリティカル率とクリティカル倍率を別々に伸ばし、両方を揃えることでクリティカル特化ビルドが完成する

最終倍率の上限、Rankごとの数値幅、部位ごとの出現ルールは未決定。

#### 攻撃速度

武器ごとの個性とMODによる成長を両立するハイブリッド型を採用する。

- 武器種類ごとに基準となる攻撃速度を持つ
- 短剣などの軽い武器は速く、大剣などの重い武器は遅いという個性を残す
- `攻撃速度 +%` MODによって、その武器の基準速度からさらに攻撃を速くできる
- 攻撃速度を伸ばしても、重い武器が最初から軽武器と同じ操作感になるような設計にはしない
- 武器の個性を残しながら、攻撃速度特化ビルドも成立させる

武器ごとの基準速度、攻撃速度の上限、Rankごとの数値幅、攻撃速度が適用される具体的な行動範囲は未決定。

#### キャスト短縮

正式名称は「キャスト時間短縮」、ゲーム内のMOD表示名は `キャスト短縮 +%` とする。

- 発動までに準備時間を持つ行動を速くする
- 魔法だけの効果には限定しない
- 魔法の詠唱、弓のチャージ、大技の溜め、回復、召喚などに適用できる
- 即時発動するスキルには効果がない
- 攻撃速度とは別の効果として扱う
- 攻撃速度は通常攻撃などの攻撃間隔を速くし、キャスト短縮はスキルが発動するまでの準備時間を短くする

キャスト短縮の上限、Rankごとの数値幅、継続発動型スキルへの適用、発動後の硬直を短縮するかは未決定。

## 拡張性

MODはコードへ直接散在させず、以下をデータ化する。

- 効果
- Rank
- 数値幅
- 部位
- タグ
- 条件
- 出現重み

将来的な武器、魔術、属性、状態異常追加に対応する。
